# Заумникъ

**Заумникъ** — интерактивный словарь редких, сложных, необычных и просто
интересных слов русского языка. Он помогает быстро понять незнакомое слово,
увидеть связанные понятия и постепенно расширять собственный лексикон.

Это не академическая энциклопедия, а живая коллекция, которую удобно изучать и
постепенно дополнять. Начальный набор намеренно невелик: новые слова и готовые
определения будут добавляться небольшими, понятными изменениями.

## Возможности

- поиск по словам, определениям, синонимам и антонимам;
- автоподсказки с управлением клавиатурой;
- навигация по буквам;
- отдельная ссылка на каждую словарную статью;
- переходы между связанными, противоположными и часто путаемыми понятиями;
- выдача результатов по десять записей;
- случайное готовое слово для свободного исследования словаря;
- адаптивный интерфейс без аналитики и внешних запросов.

## Разработка

Проект использует Node.js и Yarn Classic.

```sh
yarn install
yarn dev
```

Проверка форматирования, кода, словарных данных, интерфейса и production-сборки:

```sh
yarn quality
```

## Словарные данные

Канонические записи находятся в [`src/data/words`](./src/data/words): отдельный
YAML-файл для каждой представленной буквы. Исходная необработанная подборка
хранится только локально в игнорируемой папке `tmp/`.

Добавить слово:

```sh
yarn word:add -- "Абулия" --stress "4" --definition "Состояние ослабленной воли."
```

Допустимы `--synonyms`, `--antonyms`, а также связи `--related`, `--opposite` и
`--confused` со значениями через запятую.

После ручного изменения YAML словарь необходимо проверить и рассортировать:

```sh
yarn words:rebuild
yarn quality
```

Воспроизвести минимальный начальный набор из локального Markdown:

```sh
yarn words:import -- --seed
```

Полный импорт исходной подборки выполняется только явной командой
`yarn words:import -- --all`. Импорт без выбранного режима не изменяет данные.

Подробности:

- [формат словарной записи](./docs/data-format.md);
- [редакционный стиль определений](./docs/editorial-style.md).

## Версии

Версия хранится в `VERSION` и синхронизируется с `package.json` только через
[Bumpster](https://github.com/phoenixweiss/Bumpster). Конфигурация
`.bumpsterrc` задаёт поток `dev → main → tag` и возвращает рабочую копию на
ветку `dev`.

Перед bump Bumpster запускает `yarn quality`. Сам bump, создание тега, push и
публикация выполняются только как отдельные явно подтверждённые действия; номера
версий вручную не редактируются.
