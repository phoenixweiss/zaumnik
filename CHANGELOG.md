# История изменений

Все заметные изменения проекта описываются в этом файле.

## [Не выпущено]

## [0.3.4] — 2026-09-04

### Исправлено

- Ударение больше не повторяется на пробеле, дефисе или знаке препинания после
  ударной буквы.
- Проверка словарных данных запускается до сборки: неверные типы полей,
  позиции ударений, совпадающие адреса и ссылки на отсутствующие статьи дают
  понятную ошибку с указанием файла и слова. Исходный YAML не изменяется.
- Устранено нестабильное измерение выравнивания заголовка в браузерном тесте
  во время плавной прокрутки.

### Изменено

- Обновлены Vite до 8.2.2 и Vue-плагин до 6.0.8; для разработки и CI закреплён
  Node.js 24.20.0. Сохранены YAML-плагин и прежние целевые версии браузеров.
- Объединена обработка названий и ударений, расширены проверки Markdown-парсера
  и словарных данных, разделены браузерное и Node-окружения ESLint.
- Удалены неиспользуемые остатки «Слова дня» и дополнительные счётчики.
  Состав коллекции и оформление интерфейса не изменились: в словаре 234 статьи.

## [0.3.3] — 2026-08-30

### Добавлено

- В коллекцию добавлены статьи «Ремиссия», «Сиквел», «Приквел», «Кринж» и
  «Испанский стыд» с согласованными определениями и ударениями.
- Добавлены взаимные смысловые связи «Сиквел» ↔ «Приквел», «Кринж» ↔
  «Испанский стыд» и «Кринж» ↔ «Моветон». «Кринж» и «Испанский стыд» связаны
  по смыслу, но не указаны как синонимы.

### Исправлено

- Счётчик на главном экране правильно склоняет слово: «234 слова в коллекции».

## [0.3.0] — 2026-08-28

### Добавлено

- При опечатке поиск предлагает до трёх близких слов и показывает их как
  обычную словарную выдачу.

### Изменено

- Отправка пустого поиска открывает слово, указанное в текущей подсказке.
- Если для запроса найдены близкие варианты, Enter оставляет их для выбора,
  вместо того чтобы сразу предлагать добавить новое слово.

## [0.2.3] — 2026-08-17

### Изменено

- На мобильных экранах алфавит собран в три центрированные строки с более
  крупными кнопками.
- Мобильный подвал выстроен в компактную вертикальную стопку.

### Исправлено

- Подсказка в мобильном поле поиска больше не обрезается из-за лишних отступов
  и декоративной лупы.

## [0.2.2] — 2026-08-17

### Добавлено

- В коллекцию добавлены статьи «Кичиться» и «Чучхе» с согласованными
  определениями и ударениями.

### Изменено

- Алфавит сохраняет две центрированные строки после появления новой буквы.

## [0.2.1] — 2026-08-16

### Исправлено

- Релизная проверка подвала теперь использует текущую версию проекта.
- Публикация на GitHub Pages ожидает появления GitHub Release после создания
  нового тега.

## [0.2.0] — 2026-08-16

### Добавлено

- Полный алфавитный список слов с подгрузкой по двадцать записей.
- Кнопка копирования прямой ссылки на словарную статью.
- Фирменная карточка для публикации ссылок в социальных сетях и мессенджерах.
- Автоматическая публикация выпусков на GitHub Pages.

### Изменено

- Поиск получил отдельную кнопку отправки и более спокойное оформление
  подсказки.
- Заголовок словарной статьи стал компактнее, а наведение на строки отключено
  для сенсорных экранов.

### Исправлено

- Автоподсказки закрываются после отправки поискового запроса по Enter.
- Скорректирована высота знака ударения в поисковых подсказках.

## [0.1.0] — 2026-08-16

### Добавлено

- Коллекция из 218 слов с определениями и указанием ударений.
- Синонимы, антонимы и смысловые связи между словарными статьями.
- Поиск по словам и определениям с автоподсказками и поддержкой клавиатуры.
- Алфавитная навигация, прямые ссылки на статьи и выдача результатов по десять.
- Сценарий предложения отсутствующего слова через GitHub, YAML или электронную
  почту.
- Скрипты добавления, импорта, проверки и алфавитной пересборки словарных данных.
- Страница о проекте и способах связаться с автором.
- Адаптивный фирменный интерфейс, гильошный фон и фавиконка «Заумника».
- Автоматические проверки качества для веток `dev` и `main`.
