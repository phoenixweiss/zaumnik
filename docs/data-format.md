# Формат словарных данных

Каждой представленной в коллекции букве соответствует отдельный файл
`src/data/words/<буква>.yaml`.

```yaml
letter: А
words:
  - name: Амбивалентный
    stress:
      - 5
    definition: Вызывающий двойственные чувства; неоднозначный.
    synonyms:
      - двойственный
    antonyms:
      - однозначный
    relations:
      - word: Однозначный
        type: opposite
```

Поля записи:

- `name` — слово без знака ударения;
- `stress` — позиции ударных букв, начиная с 1; пробелы и дефисы не считаются;
- `definition` — определение, либо пустая строка для ещё не готовой статьи;
- `synonyms` — синонимы, даже если их пока нет в коллекции;
- `antonyms` — антонимы, даже если их пока нет в коллекции;
- `relations` — переходы к другим словам: `related`, `opposite` или `confused`.

Пустые поля сохраняются явно: так видно, какие сведения ещё предстоит проверить и
добавить. Неизвестные значения не заполняются предположениями.

## Служебные команды

- `yarn words:check` проверяет исходный YAML без изменения файлов: типы полей,
  позиции ударений, уникальность адресов и существование связанных слов.
  Ошибка содержит файл и статью; пустое определение допустимо, нестроковое — нет.
  Команда автоматически выполняется перед `yarn build`; та же проверка работает
  при загрузке словаря в режиме разработки;
- `yarn word:add -- "Слово"` добавляет одну пустую запись; если YAML-файла для
  первой буквы ещё нет, команда создаст его. Определение, ударение и связи можно
  передать отдельными флагами;
- `yarn words:rebuild` проверяет записи, раскладывает их по буквам и сортирует;
- `yarn words:import -- --seed` заново создаёт минимальный набор из исходного файла
  в `tmp/`;
- `yarn words:import -- --all` импортирует всю исходную подборку и потому требует
  осознанного запуска.
- `yarn words:import -- --names-only` импортирует из исходной подборки только
  названия, оставляя все редакционные поля пустыми.

Импорт без явного режима не запускается, чтобы случайно не заменить согласованный
набор слов.
